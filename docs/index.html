Why a launcher

Can't get stuck

A custom second-stage bootloader hands control back to the launcher on every normal reset. Power-cycle and you're home, whatever the app did.

Three slots

Install any ESP32-S3 firmware from the SD card, name it, give it an icon, boot it. Both full flash images and bare app images work.

No cable needed

The launcher hosts its own Wi-Fi hotspot with an upload page, or exposes the SD card as a USB drive. Add firmware from your phone.

Yours to restyle

Colours, icons and the boot animation are all replaceable from the SD card — build a theme in the browser and upload it.

Flash it

Writes the launcher at offset 0x0. Bruce and the Flipper port are not included — you add those afterwards, from the SD card.

  1. Connect the T-Embed CC1101 over USB-C. Use Chrome or Edge on desktop — Firefox and Safari have no WebSerial.
  2. Press Install launcher and choose the serial port that appears.
  3. Wait for the write to finish, then power-cycle the device.

Already running this launcher? Its USB mode blocks the flasher's auto-reset. On the device go to Settings → Power → Flash (web) and press, then hit Install. A power-cycle cancels it. A fresh device needs none of this.

Tools

Serial monitor

Watch the device's output at 115200 baud — handy when a firmware misbehaves. Disconnect before flashing; only one program can hold the port.

Manual flash

Prefer your own tools, or flashing an offline machine? Grab the image and write it at offset 0x0.

esptool --chip esp32s3 write_flash 0x0 launcher.bin

Firmware to install

Download a .bin, put it on the SD card (or upload it over Wi-Fi), then on the device: Install → pick file → pick slot.

Troubleshooting

“Install failed” when installing a firmware

Update to launcher v1.1.0 or newer. Older builds assumed every .bin was a full flash image and skipped the first 64 KB, which broke bare app images such as furi_esp32.bin. Current builds detect the layout and tell you the actual reason if something else is wrong.

My file doesn't appear in the Install list (Windows)

Windows encrypts files copied to removable drives when the source folder has the “Encrypt contents” attribute — they land as .PFILE and can't be read. Right-click your Downloads folder → Properties → Advanced → untick Encrypt contents to secure data, then copy again.

A slot says “Empty” but I installed something

A failed install erases the slot before writing, so it really is empty — reinstall. If the slot boots but shows no name, you're on an old build; newer ones label it App 2.

The flasher can't open the port

Something else is holding it — usually another browser tab with a flasher open, or a serial monitor. Close it, or unplug and replug the device.

My theme doesn't show up

Themes live in /catcolor on the SD card, not /themes — Bruce uses that one for its own themes. The Theme menu will tell you what it found.
