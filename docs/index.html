DUAL-BOOT LAUNCHER

Flash the launcher onto a LilyGo T-Embed CC1101 — browser only, no tools. Bruce / Flipper aren't included; you add any firmware later from the SD card.
  1. Plug the T-Embed CC1101 into this computer with a USB-C cable (use Chrome or Edge on desktop).
  2. Click Install and pick the serial port that appears.
  3. Let it erase & flash. When it finishes, power-cycle and it boots into the launcher.
Your browser can't flash — please use Chrome or Edge on desktop. This page must be opened over https:// (or localhost).

Fresh device? The steps above are all you need.
Already running this launcher? Its USB mode blocks auto-reset, so first put it in download mode on the device: Settings → Power → Flash (web) → press, then click Install. A power-cycle cancels download mode.
Prefer a manual flash? Download launcher.bin and write it at offset 0x0 with esptool.
