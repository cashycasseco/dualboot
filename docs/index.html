LILYGO T-EMBED CC1101

ONE DEVICE
EVERY FIRMWARE

A launcher that boots first, every time — then runs Bruce, the Flipper port, or anything else you drop on the SD card. Three slots. Switch in seconds. You can never lock yourself out.

CHROME OR EDGE REQUIRED NEEDS HTTPS BROWSER ONLY · NO TOOLCHAIN · 1.3 MB

SCREENS

Rendered from the firmware's own assets — the same icon masks, sprites and bitmap font the device draws with. 320×170, double-buffered out of PSRAM.

WHY

NO DEAD ENDS

A custom second-stage bootloader hands control back to the launcher on every normal reset. Power-cycle and you're home, whatever the app did.

THREE SLOTS

Install any ESP32-S3 firmware from the card, name it, give it an icon, boot it. Full flash images and bare app images both work.

NO CABLE

The launcher hosts its own Wi-Fi hotspot with an upload page, or exposes the SD card as a USB drive. Load firmware from your phone.

RESTYLABLE

Colours, icons and the boot animation all come off the SD card. Build a theme in the browser and upload it.

FLASH

Writes the launcher at offset 0x0. Bruce and the Flipper port are not included — those go on afterwards, from the SD card.

  1. Connect the T-Embed CC1101 over USB-C. Chrome or Edge on desktop — Firefox and Safari have no WebSerial.
  2. Hit INSTALL LAUNCHER and pick the serial port.
  3. Let the write finish, then power-cycle.

TOOLS

SERIAL MONITOR

Watch the device at 115200 baud when a firmware misbehaves. Disconnect before flashing — only one program can hold the port.

MANUAL FLASH

Own tools, or an offline machine? Take the image and write it at offset 0x0.

esptool --chip esp32s3 write_flash 0x0 launcher.bin

WHEN IT BREAKS

"Install failed" while installing a firmware

Update to v1.1.0 or newer. Older builds assumed every .bin was a full flash image and skipped the first 64 KB, which broke bare app images like furi_esp32.bin. Current builds detect the layout and name the real reason if something else is wrong.

My file isn't in the Install list (Windows)

Windows encrypts files copied to removable drives when the source folder has the "Encrypt contents" attribute — they land as .PFILE and can't be read. Right-click your Downloads folder → Properties → Advanced → untick Encrypt contents to secure data, then copy again.

A slot says "Empty" but I installed something

A failed install erases the slot before writing, so it really is empty — reinstall. If it boots but shows no name, you're on an old build; newer ones label it App 2.

The flasher can't open the port

Something else holds it — usually another tab with a flasher open, or a serial monitor. Close it, or unplug and replug the device.

My theme doesn't show up

Themes live in /catcolor on the card, not /themes — Bruce uses that one. The Theme menu reports what it found.
