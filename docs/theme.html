THEME CREATOR

Build a complete theme pack for the Dual-Boot Launcher — colours, your own icons and your own boot animation (drop in a GIF, it's converted for you). Everything happens in your browser; nothing is uploaded. ← back to the flasher

1 · BASICS

0% turns the LEDs off.

2 · PREVIEW

Approximate — the device uses its own bitmap title font. Icons and colours are exact.

3 · ICONS (optional)

Click an icon to replace it with your own image (PNG, SVG, JPG). It's scaled to 48×48 and reduced to a 1-bit mask — the launcher tints it to match the theme, so shape is all that matters. Transparent PNGs work best. Click a replaced icon again to re-upload, or use invert / reset below it.

using built-in icons

4 · BOOT ANIMATION (optional)

Drop in an animated GIF (or WebP/APNG, or several still images) and it's converted into the launcher's frame format automatically — cropped to the screen's shape, resized and written as .raw frames.

no animation — the built-in one is kept

5 · DOWNLOAD & INSTALL

Easiest — over Wi-Fi: on the device pick WiFi in the main menu, join the hotspot it shows, open http://192.168.4.1 and upload this .zip. It's unpacked on the device for you.

  1. Or by card: unzip it into a /catcolor folder on the SD card, so you get /catcolor/<your-theme>/. (Not /themes — Bruce uses that one.)
  2. Or over USB: pick USB in the main menu — the SD card shows up as a drive on your PC.
  3. Then on the device: Settings → Design → Theme → pick your theme. Colours, icons and the boot animation all switch over instantly.
⚠ Windows users — if the theme doesn't show up on the device

Windows can silently encrypt files copied to removable drives, renaming them to theme.txt.PFILE, icons.bin.PFILE … and adding an $EFS file. The launcher can't read those — the theme looks missing. If you see .PFILE names on the card, delete them and copy the pack again with that data protection turned off (it comes from a Windows Information Protection / "personal data encryption" policy). Extracting the ZIP directly onto the card, rather than copying already-extracted files, usually avoids it too.
